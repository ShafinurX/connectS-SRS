## 📋 Overview

This repository contains the complete **Software Requirements Specification (SRS)** for the **connectS** mobile application. connectS is a Flutter-based academic ecosystem designed for institutional academic coordination.

The document covers all functional and non-functional requirements, use case diagrams, data modeling, class-based modeling, architectural design, quality attributes, and testing plan.

---

## 🎯 Key Features

- Role-based access control (Student, Teacher, CR, Admin, Office Staff)
- Centralized notice & news feed system
- Assignment deadline management with push notifications
- CT & CA marks management
- Digital application & approval workflow
- Teacher consultation scheduling
- Permanent resource storage (slides & books)
- Dark / Light mode support
- Mini quiz feature
- Student online handles integration
